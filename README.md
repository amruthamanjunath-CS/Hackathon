# Remind & Reconnect: A Gentle Companion for Dementia Care

A gentle web application designed for mild-to-moderate dementia patients and their family caregivers.

## Features
- **Patient Interface:** Large touch targets, gentle audio reminders, memory photos, and non-judgmental cognitive games.
- **Caregiver Dashboard:** Engagement analytics, routine management, and automated anomaly detection alerts.
